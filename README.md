# PKFX Scanner

Purple cyberpunk dashboard for PKFX — AI-powered forex alerts, courses, and e-books.

## Quick start

```bash
npm install
npm run dev
```

Open the local URL Vite prints (default `http://localhost:5173`).

## Scripts

- `npm run dev` — start development server
- `npm run build` — production build
- `npm run preview` — preview production build

## Pages

- Sign In (`/`)
- Dashboard (`/dashboard`) — alerts, how-it-works video, stats
- My Alerts (`/alerts`)
- E-Books (`/ebooks`)
- Courses (`/courses`)
- Profile modal (`/profile`)
- Scanner modal via **Edit Scanner**
